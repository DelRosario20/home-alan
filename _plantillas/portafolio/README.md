# Plantillas de portafolio

Copiar los tres archivos para cada proyecto y reemplazar `tema-ejemplo` por el mismo `slug` en todos.

- `tema-ejemplo.qmd`: puerta común del caso.
- `tema-ejemplo-research.qmd`: producto académico.
- `tema-ejemplo-dashboard.qmd`: producto BI.

Antes de usarlas, leer `_gobernanza/ARQUITECTURA_PORTAFOLIO.md`, `PROTOCOLO_CALIDAD.md` y `CHECKLIST_PUBLICACION.md`.

El alta se automatiza con la skill `nuevo-caso`; el desarrollo de cada eje, con `articulo-academico` (estilo boletín BCE) y `dashboard-bi` (estilo IRE MEF). Referencias canónicas en `ARQUITECTURA_PORTAFOLIO.md` §2.
